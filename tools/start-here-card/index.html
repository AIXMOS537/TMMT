TMMT Auto Services · One-button guide

Start Here

1.Double-click the START‑HERE icon 2.Press a number, then Enter
  • 1 Turn it on   — set up this device and connect it
  • 2 See everyone   — which devices are online right now
  • 3 Get help   — buzz the owner to come help you
  • 4 Do work   — start the helper agents
  • 5 Open the app   — run the TMMT app on this device
  • 6 Update   — get the very latest
  • 7 Check   — is everything okay and safe?
  • 0 Done   — close this menu
● You can’t break anything.
Not sure? Just press 3 and the owner comes to help.
How to open it
Mac — double-click START-HERE.command
Windows — double-click START-HERE.cmd
Anything else — bash scripts/start.sh
