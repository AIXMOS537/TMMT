- [ ] Stand up a continuous removal service (Tab C)
- [ ] Google "Results about you" deindex requests filed

### Week 2 — Compartmentalize (Pillar 3)
- [ ] Email-masking service live; aliases for all signups
- [ ] X public email created (separate from root)
- [ ] VoIP / business line(s) provisioned; X has its own number
- [ ] Virtual mailbox / PO box live
- [ ] Per-vendor virtual cards set up where possible
- [ ] Migrate existing public contact points to alias/VoIP/virtual address

### Week 3 — Shield (Pillar 2)
- [ ] Registered agent + virtual address chosen
- [ ] Swap home address → registered agent on every state filing
- [ ] WHOIS privacy on **every** domain
- [ ] No domain registered in personal name/address
- [ ] Entity/trust asset-titling review booked with attorney/CPA
- [ ] Bills / subscriptions / deliveries moved to business identity

### Week 4 — Harden + Surface (Pillars 4, 5, 6)
- [ ] Vault: unique credentials everywhere, nothing reused
- [ ] App/passkey 2FA on everything (drop SMS where possible)
- [ ] Carrier port-out / SIM-swap PIN set
- [ ] Root identity email on hardware-key/app 2FA; recovery info clean
- [ ] Build/clean the **X node** (owned site/profile, page-one SEO)
- [ ] All CTAs/bios/contracts route to X
- [ ] Quarterly re-audit added to the calendar (recurring)
- [ ] Vault map of alias ↔ number ↔ entity created
