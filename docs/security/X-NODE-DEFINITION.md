# X = AIXMOS — the one public node

> Pillar 5 of [`GO-GHOST-PROTOCOL.md`](./GO-GHOST-PROTOCOL.md), made concrete.
> This is the single name the world sees. The legal you (**GHOST**) stays behind
> it. Everything public points here.

## The decision (locked)

**X = AIXMOS**, the public brand at **`allinonemanagementsolutions.com`**.

This isn't a new invention — your domain architecture
([`../DOMAIN-SETUP.md`](../DOMAIN-SETUP.md)) already splits exactly along the
GHOST/X line:

| Layer | Surface | Who sees it | Role |
|---|---|---|---|
| **X (public)** | `allinonemanagementsolutions.com` — **AIXMOS** | Everyone | The only thing discoverable |
| **GHOST (private)** | `allinonemanagementsolutions.net` — command desk | **Owner only** | Never marketed, never indexed |
| **Entity front** | **All In One Management Solutions** | Public record | Holds the public-facing obligations |

So the public funnel is X; the `.net` command desk is the ghost. Keep that wall
absolute: **the `.net` and the owner's personal identity never appear on the
`.com` or anywhere public.**

## What X *is* (the public statement)

> **AIXMOS** — All In One Management Solutions. A management/operations network
> for vehicle rental, credit guidance, and business systems. Inbound: partners,
> clients, operators applying.

## What X is **not**

- Not tied to any person's legal name, home address, or personal cell/email.
- Not a window into the owner. X is a brand/entity, full stop.

## Own page one (SEO)

- One **authoritative home**: the `.com` you control — states what AIXMOS is,
  nothing personal.
- **Consistent handle** — `@aixmos` (or the closest you can secure) across only
  the platforms you actually want indexed.
- Make the `.com` the default result so searching the brand returns *your* node,
  not a broker page. (`aixmos.com` is also in your name — point it at the same
  node or redirect it in, so it can't be squatted against you.)

## "Appear when needed" (activation protocol)

X is always **ready but quiet**. You light it up deliberately — a deal, a launch,
a press moment — then it goes still. The mechanics already exist:

- The public `.com` is always live (the storefront).
- You drive activity from the **`.net` command desk** and the M1 brain
  (`brainiac-mac`) — push a campaign, answer inbound, then stand down.
- `dark`/`light` (`scripts/godark`) is the kill/quiet switch if you ever need X
  to go silent fast.

## The wall (non-negotiable)

1. Owner's legal name / home / personal cell / personal email → **never** on the
   `.com`, never in WHOIS, never on a public filing. (Entity + registered agent
   instead.)
2. The `.net` command desk is **bookmark-only** — not linked from anywhere public.
3. New public-facing anything is born as **AIXMOS**, through an alias, on the
   virtual address. Default to the entity, never yourself.
