# 👔 Executives-Only Org — agents are the workforce

> The staffing model: **agents do the labor, humans are executives only.** No
> overseas task-VAs, no rooms of cheap labor. Every human seat is high-leverage —
> judgment, relationships, the close, compliance. Open: **`org`** (or `team`).
> Companions: `docs/FUNDING-AGENCY-PLAYBOOK.md`, `docs/WATCHTOWER-ROSTER.md`,
> `docs/SOVEREIGN-OPERATOR.md`.

## The one rule
**If it's repeatable, an agent does it. If it needs judgment, an executive does it.**
You never hire a human for work an agent can run. That's the margin, the control,
and the quality — all at once.

## 🤖 The workforce = agents (no VAs)
Agents own the entire grind, 24/7, in-house:
- Outbound replies, intake, qualifying
- Document collection + chasing missing items
- Follow-up sequences, nudges, status updates
- Lead triage (`moe-hot`), scheduling, FAQs, support
- Reporting, daily briefs (`moe-brief`), pipeline hygiene

→ This is what used to be 10 overseas VAs. Now it's the agent layer.

## 👔 The only humans = executives (the seats you actually fill)
Few, sharp, high-leverage. Each is an *executive*, not a task-rabbit:

| Exec seat | Owns (judgment work) | Who |
|---|---|---|
| **Owner / CEO** | vision, the platform, capital, final calls | You (PROJECT X) |
| **Operator / Agency Lead** | runs a vertical/agency, owns clients + relationships | Umar (MoeLegacy) + future operators |
| **Closer / Placement Exec** | the close + lender/funding placement strategy | you / a sharp closer |
| **Compliance / Counsel** | fee structure, CROA/TCPA/FCRA sign-off | fractional attorney |
| **Growth Exec** *(optional)* | ads strategy + scaling spend | you / a media buyer |

That's it. **4–5 judgment seats**, each worth equity/real pay — not 20 cheap hands.

## Why this wins
- **Margin:** agents cost compute, not salaries. More profit per client.
- **Control + IP:** the work + know-how stay **in-house, yours** — not on overseas contractors' laptops.
- **Quality + speed:** agents don't sleep, don't drift, don't churn.
- **Clean scale:** each new operator is an *executive* running agents — clone the
  agency (`new-operator`), not a call center.
- **Dignity:** the humans you do bring on are partners/operators with upside —
  that's the network, not a sweatshop.

## How it maps to what's built
- **Agents:** AIXMOS layer + GHL automations + `/learn` + `moe-hot`/`moe-brief`.
- **Executives:** the League (`docs/WATCHTOWER-ROSTER.md`) — Boss, operators
  (Nightwing/Red Hood), placement, compliance.
- **Each operator = a sovereign executive** running agents on your platform
  (`docs/SOVEREIGN-OPERATOR.md`), protected + paid (`docs/deal-kit/`).

## The hiring filter (use it every time)
Before hiring a human, ask: **"Can an agent do this?"**
- Yes → an agent does it. No hire.
- No, it needs judgment/relationships/risk → that's an **executive** seat.
