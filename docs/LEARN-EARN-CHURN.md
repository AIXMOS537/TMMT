## How it runs (engine today → full build later)
- **Today:** `scripts/member` enrolls a member locally (venture/role/level),
  prints their starter path + the DLC ladder. Owner-run, local-first, no secrets.
- **Onboarding wizard:** `scripts/aixmos onboard` (the 10-step decode) feeds the
  member's foundation; `scripts/activate-operator.command` records grants when
  someone steps up to operator.
- **As the build rolls out:** each venture/role gets its real resource pack
  (playbooks, funnels, automations, agent) delivered automatically by level —
  that's the roadmap this engine seeds.
- **Honesty (always):** we sell the **system + path**, never guaranteed income.
  Credit = **"guidance," never "repair."** Members consent + verify before any
  likeness/scan (`docs/deal-kit/digitization/`).
