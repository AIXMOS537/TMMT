operators across Arizona (credit/funding, car rentals, marketing, e-commerce),
each running their **own sovereign agency** on the **Owner's licensed platform.**
Every operator signs the same protected agreement, pays the same way, and plugs

## Owner-first protection (on every operator, not just one)

The protection is the *system*, applied to all:
- **You own the platform/IP; they license it** (revocable) —
  `deal-kit/PLATFORM-LICENSE-AND-OPERATOR-AGREEMENT.md`.
- **You're paid on every one** — setup + monthly license + optional revenue share;
  **non-payment auto-suspends access** (`deal-kit/PAYMENT-SCHEDULE.md`).
- **Each operator is isolated** (own Tailscale account/tenant) — one operator's
  problem never touches you or another (`docs/SOVEREIGN-OPERATOR.md`).
- **You can revoke any operator instantly** (license + Tailscale share + hosting).
- **Family first** — diversified across many operators, you're not dependent on any
  single one; the platform (and its revenue) is the asset you own. (`compass`.)

## The repeatable pipeline (one command per operator)

```
  RECRUIT → STAMP → SIGN → ONBOARD → BUILD → LIVE → (paid, monthly)
```

1. **Stamp** (one command, you protected from the start):
   ```
   new-operator "Name" "Agency" "vertical" [monthly$] [email]
   ```
   → fills their Platform License + Payment Schedule + invite (local, owner-only).
2. **Sign** — counsel reviews the kit once; every operator signs the same papers.
3. **Onboard** — `invite operator "Name" their@email` (Mail opens, written) →
   they run the one-paste `operator-start.sh` on their Mac.
4. **Build** — `engineer add "Agency"` (pick their machine) → stand up their
   branded tenant + forms + GHL (portal is ~90% pre-built).
5. **Live & paid** — they take clients; you collect monthly, auto-charged.

## Guardrails (so growth never costs you)
- No operator gets owner authority or the source — license only.
- Every operator signs **before** their org is built (`new-operator` first).
- Compliance enforced per vertical (credit = "guidance," never "repair").
- Isolation by account = one bad actor can't reach the rest or you.
