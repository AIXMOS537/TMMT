## What's in each file

1. **One-liners** — short positioning lines, drop-in for captions, CTAs, profile bios
2. **Customer-facing pitch (long form)** — the lifted section 11 customer block, drop-in for landing pages and DMs
3. **Hooks bank** — 10–12 short-form openers labeled by tone (identity / curiosity / contrarian / proof / urgency)
4. **Comment & DM reply stock** — pre-approved responses to common comment-section objections
5. **Compliance reminder** — what you cannot say in any creative, on any platform

---

## How to use these files

**For ad creative (TikTok / Reels / Snap):**
- Pick 1 hook from the bank
- 2–3 seconds of visual proof (vehicle B-roll, customer-on-camera, screen recording of the portal)
- End on the CTA from the program deck's section 12

**For organic content:**
- Use the hooks bank to A/B test cold opens
- Cross-pollinate hooks across programs (the L2O hook bank often works for credit guidance with a single-word swap)

**For comments and DMs:**
- Use the comment-reply stock — don't free-write
- If someone asks something not in the stock, send to the universal compliance footer first, then draft a response, then ship

---

## Universal compliance reminder

Apply to every creative, every caption, every comment, every DM:

❌ Never: "credit repair," "guaranteed approval," "guaranteed score," "we'll fix your credit," "guaranteed funding amount or rate," "no risk," specific score/timeline pairs, deletion promises

✅ Always: use the program's published pricing, route to the correct CTA, apply the correct GHL tag

Full rules: [`../README.md#universal-compliance-footer`](../README.md#universal-compliance-footer)

---

## Process: how to add new creative copy back to these files

If a hook works (high CTR, good comments-to-views ratio), don't let it die in an ad account. Add it to the hooks bank with the metric attached so the team can reuse:

```markdown
- **"Stop scrolling if ___"** (identity) — *winner on TikTok Apr 2026, 6.8% CTR — TMMT-paid ad #4421*
```

Same loop for a comment reply that diffuses an objection — promote it into the stock list.
