# Deal Kit — close fast, get paid, start building

> ⚠️ **These are templates, not legal advice.** Have a licensed attorney in your
> state review before sending anything. They exist to move fast *and* stay protected.

## One command does the paperwork

```bash
bash scripts/new-deal.sh "Client Name" 25000 "$25K — credit + funding + rentals"
# word form:  deal "Client Name" 25000 "$25K — ..."
```

Generates, in `.hailmary/deals/<client>/` (owner-local, gitignored):
- **engagement-letter.md** — scope, **50% deposit**, balance, compliance, remote access
- **remote-access-consent.md** — consented, logged RustDesk takeover
- **discovery-intake.md** — the 10-layer decode that starts the build
- **invoice-deposit.md** — the deposit invoice

## The flow

`docs/deal-kit/CLOSE-CHECKLIST.md` — lead → pitch → paper → **deposit = GO** →
discovery → build → live.

## The rules baked in

- **50% deposit triggers the work.** No deposit, no start.
- Sell the **system + build + management** — never guaranteed income.
- Credit = **"guidance," never "repair."**
- Remote access is **consented + logged**, least-privilege.

Pricing source of truth: `docs/OFFER-STACK.md`.
