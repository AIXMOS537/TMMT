# TMMT premium site

GitHub Pages-ready marketing page for TMMT (Rentals · Restoration · Auto).

## Local

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## GitHub Pages

1. Push this folder as a repo (or `/docs` on an existing repo).
2. Settings → Pages → Deploy from branch → root.
3. Site serves at `https://<user>.github.io/<repo>/`.
