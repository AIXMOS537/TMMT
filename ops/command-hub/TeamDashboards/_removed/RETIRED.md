# Retired consoles

Moved out of the active roster on 2026-08-26.
These are the previous operator crew. Their consoles are kept here rather than
deleted so a returning person can be restored quickly - re-add them to
`tools/profiles.json` and run `node tools/build-consoles.js`.

Access is NOT controlled by these files. Removing someone from the roster stops
producing their console; it does not revoke anything. Off-boarding still means
removing them in Supabase, GoHighLevel, Slack and OpenPhone. See ONBOARDING.md.
