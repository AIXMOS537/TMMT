# FAST-TRACK CLOSE — lead → paid → building

> The repeatable flow that turns a "yes" into money in the account and a project
> underway. One command generates the paperwork: `bash scripts/new-deal.sh`.

```
 LEAD  →  PITCH  →  PAPER  →  DEPOSIT  →  DISCOVERY  →  BUILD  →  LIVE
```

## 1. Lead
- Hand them the right asset: **FOUNDER-WELCOME.pdf** (founders) or the per-tier
  pitch / **OFFER-STACK** (paying clients), + **GLOBAL-MESH-JOIN** card.

## 2. Pitch
- Match them to a tier (OFFER-STACK ladder). Anchor on the **50% deposit = GO**.
- Be honest: sell the **system + build + management**, never guaranteed income.

## 3. Paper (one command)
```bash
bash scripts/new-deal.sh "Client Name" 25000 "$25K — credit + funding + rentals"
```
→ generates, in `.hailmary/deals/<client>/`:
- **engagement letter** (filled: total, 50% deposit, balance, scope)
- **remote-access consent**
- **discovery intake**
- **deposit invoice**

Review with counsel, send to the client.

## 4. Deposit
- Client signs + pays **50%**. Deposit clears → the clock starts.
- Record it (founders: log hours/commission toward their $50K instead).

## 5. Discovery (auto-trigger)
- Fill **DISCOVERY-INTAKE** → relay requirements across the network.
- `onboard` wizard can capture the same 10 layers interactively.

## 6. Build
- `motherbox` flash the node · `setup-llm` the brain · GHL + Airtable + agents.
- Owner remote-in (consented RustDesk) to run the backend.

## 7. Live
- Add their URL to `watch/targets.tsv` → green in `health`.
- Monthly backend support begins. Watch everything from `fatherbox`.
