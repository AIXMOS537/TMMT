TMMT Simple Setup Guide

For: Muhammad / TMMT team

This paper tells you what to click. You do not need to be a computer expert.

Remember these 3 websites:

WhoWebsite to open
Your team (office)tmmtrentals.com

Why login broke

Someone typed tmmtrentals.net as the “mail computer address.” That is wrong. A mail computer address looks like smtp.mailgun.org — you get the real one from GoHighLevel.

Part 1 — Fix login emails (GoHighLevel → Supabase)

Do this first. About 30–60 minutes. Wait for green checkmarks.

  1. Open gohighlevel.com and log in.
    Pick your shop: TMMT Rentals (not the whole agency).
  2. Click the gear ⚙ Settings (bottom left).
  3. Find Email Services or LC Email. Click it.
  4. Click Dedicated Domain → add tmmtrentals.net.
  5. GHL shows a list of DNS records (little codes).
    Open Squarespace → Domains → tmmtrentals.net → DNS → add each record GHL shows.
    Come back tomorrow if it says “waiting.” That is normal.
  6. When GHL says the domain is Verified ✓, go to SMTP Settings (same email area).
    Click Create SMTP credentials. Copy these 4 things on paper:
    ☑ Host   ☑ Port   ☑ Username   ☑ Password
  7. Open supabase.com → your project → Authentication → SMTP Settings.
  8. Turn ON custom SMTP. Paste the 4 things from step 6.
    Sender email: noreply@tmmtrentals.net
    Sender name: TMMT Rentals
    Click Save.
  9. Still in Supabase: Authentication → URL Configuration.
    Add these lines (one per line):
    https://tmmtrentals.net/**   https://tmmtrentals.com/**   https://tmmt-ops.vercel.app/**   http://localhost:3000/**
  10. Test: open tmmtrentals.net/login → Magic link tab → your email → Send.
    Check your inbox (and spam). Click the link. You should get in. ☐ It worked!

Part 2 — Who uses which website

You do not buy Gmail for every person.

  • ☐ Team → send them tmmtrentals.com/login
  • ☐ Customers & partners → send them tmmtrentals.net/login
  • ☐ Your one Google email → only for YOU to read mail (optional)

Part 3 — GoHighLevel sends “open your portal” emails

After Part 1 works, add ONE simple workflow in GHL.

  1. GHL → Automation → Workflows → Create workflow.
  2. Name it: Send portal link when booked.
  3. Trigger: Opportunity stage changed → Pipeline TMMT Rentals → Stage Booked.
  4. Action: Send Email.
    Subject: Your TMMT portal
    Message: Hi! Open your portal here: https://tmmtrentals.net/login
    Then they can click Magic link on that page.
  5. Turn workflow ON. ☐ Done

Part 4 — Make someone an admin (one time)

  1. They sign up once at tmmtrentals.com/login (or .net).
  2. Supabase → SQL Editor → paste and change the email:
    update public.profiles set role = 'admin' where email = 'YOUR-EMAIL@HERE.com';
  3. Click Run. They can open the team dashboard. ☐ Done

Part 5 — If you are stuck

  • Magic link still fails? → Part 1 step 6–8 again. Host must NOT be “tmmtrentals.net”.
  • Need in right now? → Login page → Password tab (ask your tech person to set a password).
  • Blank page on cases? → Refresh. Or use tmmt-ops.vercel.app instead.

Checklist — am I done?

  • ☐ GHL domain tmmtrentals.net = Verified
  • ☐ Supabase SMTP = filled in from GHL (not the word tmmtrentals.net as host)
  • ☐ Magic link email arrives
  • ☐ Team uses .com link
  • ☐ Customers use .net link
  • ☐ GHL “Booked” workflow sends portal link
