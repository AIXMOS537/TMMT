## The one move

```bash

```

Boots the whole base (update + HAILMARY + memory loop + always-on). After a fresh
deploy, open a new terminal and type it. Lost? type `menu`.

## The locks (what keeps it yours)

1. **Owner gate** — `auth/OWNER.seal`; owner role needs your passphrase.
2. **Secrets never in git** — pre-commit/pre-push guard.
3. **Fail-closed auth** + **Tailscale-only** mesh you approve device-by-device.
4. **`dark`** — anyone can stop everything; only your word restarts it.
5. **`compass`** — protects the user first, even during blackout.
