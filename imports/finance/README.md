**Owner:** Muhammad Taha · **Principle:** God → self/wellbeing → family → others

## How to use

1. Edit `master-bills.csv` — one row per bill (personal, family, TMMT, Moe Legacy, AIXMOS).
2. Drop bank CSV exports here (gitignored): `imports/finance/statements/*.csv`
3. Run: `bash scripts/tmmt finance sweep`
4. Give Claude the full build: `bash scripts/tmmt finance claude`

## Committee / BC (what your parents taught)

**Committee** (also called BC in some communities) = a **rotating savings group**: everyone pays in on a schedule; each cycle one member receives the pot. Discipline, trust, and priorities **before** spending.

This project carries that idea into software:

- **Token ledger** (`docs/superpowers/specs/2026-06-18-tmmt-token-ledger.md`) — monthly stack, spend on jobs, no runaway API bills
- **Operator seats** — pay → get fenced access → renew or top up
- **Your personal committee** — fund God/family/self buckets **first** in `master-bills.csv` Priority Tier column, then business tools
